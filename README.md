# 🏷️ دليل نظام طباعة الباركود الحراري - مخازن ومحلات نيللي (Nelly System)

دليل شامل وتوثيق هندسي متكامل لنظام توليد وطباعة ملصقات الباركود الحرارية (Thermal Barcode Labels) للمنتجات والموظفين عبر طابعات الباركود الحرارية في مشروع **مخازن ومحلات نيللي للميكاب ومستحضرات التجميل**.

## 1. نظرة عامة على النظام

تم تصميم نظام الباركود في مشروع نيللي لتوليد وطباعة ملصقات فورية بدون أي إطارات خارجية (`Borderless`) وبخطوط عريضة وكبيرة مقروءة بوضوح بالعين المجردة وقابلة للمسح الفوري بواسطة ماسحات الباركود الليزرية (Barcode Scanners) أو كاميرات الهواتف.

### المزايا الأساسية:
* **بدون إطار خارجي (100% Borderless):** تم إلغاء الإطارات الخارجية لمنع قصها أو تشوهها على حواف الاستيكرات الحرارية.
* **خطوط عريضة وكبيرة وواضحة:** خطوط اسم المنتج/الموظف، الكود الرقمي، والأسعار تم تكبيرها لتبدو مقروءة وبارزة جداً.
* **محرك طباعة ذري عالي الدقة (300 DPI Canvas):** يمنع متصفح كروم من تقطيع الملصق إلى صفحات متعددة (Pagination Avoidance).
* **طباعة فورية معزولة (Isolated Hidden Iframe):** لا تتأثر بأنماط صفحة الموقع ولا تظهر هوامش المتصفح الافتراضية.
* **تصدير كصورة رقمية (PNG Download):** إمكانية تنزيل ملصق الباركود كصورة عالية الجودة بضغطة زر.
* **دعم جميع مقاسات الاستيكرات:** يدعم الرولات الصغيرة (38×20 مم، 38×25 مم) والرولات الكبيرة القياسية (50×30 مم، 50×25 مم، 50×40 مم، 60×40 مم).

## 2. المكتبات والتقنيات المستخدمة

| التقنية / المكتبة | الإصدار | الوظيفة ودورها في النظام |
| :--- | :--- | :--- |
| **`jsbarcode`** | `^3.12.3` | مكتبة متخصصة في توليد خطوط الباركود المتجهة (Vector SVG) بصيغة **Code128** العالمية عالية الدقة، مع تصفير الهوامش لضمان أقصى عرض للخطوط. |
| **`HTML5 Canvas API`** | Native | محرك رسم نقطي بدقة **300 DPI (12 بكسل لكل مم)** يقوم بدمج النصوص والباركود والشعار في صورة ذرية واحدة غير قابلة للتجزئة. |
| **`XMLSerializer` & `Blob`** | Native | استخراج شفرة الـ SVG البرمجية وضمان احتوائها على مساحة الأسماء `xmlns="http://www.w3.org/2000/svg"` لتحويلها إلى صورة خالية من الأخطاء. |
| **`Isolated Hidden Iframe`** | Native | إطار طباعة مخفي يتم إنشاؤه ديناميكياً لتمرير كود الطباعة وقواعد `@page` بأبعاد الاستيكر الدقيقة دون التأثير على واجهة المستخدم. |
| **`lucide-react`** | `^1.16.0` | أيقونات واجهة المستخدم التفاعلية (أيقونة الباركود، الطابعة، التنزيل، النسخ). |

## 3. البنية الهندسية وكيفية عمل محرك الطباعة

```
[كود الباركود / بيانات الموظف أو المنتج]
                    │
                    ▼
       1. توليد كود الـ SVG المتجه
         (JsBarcode - Code128)
                    │
                    ▼
       2. المعالجة وضمان مساحة الأسماء
   (XMLSerializer + xmlns="http://www.w3.org/2000/svg")
                    │
                    ▼
       3. الرسم فائق الدقة (300 DPI Canvas)
    - خلفية بيضاء نقية
    - خطوط عريضة وكبيرة (اسم، كود، سعر)
    - بدون إطار خارجي نهائياً (Borderless)
                    │
                    ▼
       4. إنتاج الصورة الذرية (Atomic PNG)
           (canvas.toDataURL("image/png"))
                    │
       ┌────────────┴────────────┐
       ▼                         ▼
  [تنزيل كصورة PNG]       [الطباعة الحرارية المعزولة]
                      (Isolated Hidden Iframe + @page)
```

### لماذا فشلت الطباعة التقليدية (`window.print()`) وتم استبدالها؟
1. **مشكلة تقطيع الصفحة (Page Splitting):** أمر الطباعة العادي يتعامل مع عناصر HTML (نصوص + div + svg) كعناصر منفصلة، وفي المقاسات الصغيرة (مثل 20 مم) يظن المتصفح أن المحتوى يتجاوز الصفحة فيقطعه على 3 إلى 5 استيكرات!  
   * **الحل الهندسي:** رسم كل شيء في **صورة واحدة فقط (`<img />`)** بأبعاد الاستيكر الدقيقة؛ فالصورة عنصر ذري غير قابل للتقطيع (`page-break-inside: avoid;`).
2. **مشكلة هوامش المتصفح:** أمر `window.print()` يطبع الصفحة كاملة مع القائمة الجانبية وتاريخ اليوم والرابط.  
   * **الحل الهندسي:** طباعة الـ `iframe` المعزول مع قاعدة `@page { size: W mm H mm; margin: 0; }`.

   * **الصفحات المرتبطة:**

   * **البيانات المطبوعة:** اسم الموظف، شعار نيللي، باركود كود البصمة، كود الموظف، المسمى الوظيفي.

## 5. جدول المقاسات القياسية (ملليمتر والإنش)

عند إدخال المقاسات في تعريف طابعات الباركود (Windows Driver)، استخدم الجدول التالي بحسب نوع الرول المستخدم لديك:

| اسم الرول | العرض (Width) | الارتفاع (Height) | العرض بالإنش (Inches) | الارتفاع بالإنش (Inches) | الفاصل (Gap) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **50 × 30 مم (القياسي الجديد)** | **50.0 mm** | **30.0 mm** | **1.97 in** (أو 2.00") | **1.18 in** (أو 1.20") | 2.0 mm / 0.08" |
| **50 × 25 مم (عريض)** | **50.0 mm** | **25.0 mm** | **1.97 in** | **0.98 in** (أو 1.00") | 2.0 mm / 0.08" |
| **50 × 40 مم (كبير جداً)** | **50.0 mm** | **40.0 mm** | **1.97 in** | **1.57 in** (أو 1.60") | 2.0 mm / 0.08" |
| **60 × 40 مم (جامبو)** | **60.0 mm** | **40.0 mm** | **2.36 in** | **1.57 in** | 3.0 mm / 0.12" |
| **38 × 25 مم (وسط)** | **38.0 mm** | **25.0 mm** | **1.50 in** | **0.98 in** (أو 1.00") | 2.0 mm / 0.08" |
| **38 × 20 مم (صغير)** | **38.0 mm** | **20.0 mm** | **1.50 in** | **0.79 in** (أو 0.80") | 2.0 mm / 0.08" |

> 📌 **معادلة التحويل:** `1 إنش = 25.4 ملليمتر`.

## 6. دليل معايرة الطابعة الحرارية وحساس الفواصل (Auto-Calibration)

إذا قمت بتغيير مقاس الرول ووجدت أن الطابعة تطبع نصف الباركود في استيكر ونصفه الآخر في الاستيكر التالي، فالسبب هو أن **حساس الفواصل (Gap Sensor)** يحتاج إلى معايرة ليتعلم طول الاستيكر الجديد.

### خطوات المعايرة القياسية (لمعظم الطابعات مثل Xprinter و Rongta و TSC):
1. **أغلق الطابعة تماماً** من زر الباور (OFF).
2. تأكد أن رول الاستيكر مركب بشكل سليم ويمر تحت الموجهات البلاستيكية.
3. **اضغط باستمرار على زر التغذية (FEED)** في واجهة الطابعة بدون رفع إصبعك.
4. وأنت ما زلت ضاغطاً على زر FEED، **قم بتشغيل زر الباور (ON)**.
5. استمر بالضغط حتى تسمع صفارة مرتين (**Beep Beep**) أو يومض الضوء الأحمر، ثم **ارفع إصبعك فوراً**.
6. ستقوم الطابعة بسحب استيكرين أو ثلاثة ببطء شديد وتتوقف **تلقائياً عند خط القطع الفاصل بين الاستيكرين**.

> ✅ **الاختبار:** اضغط ضغطة واحدة عادية على زر FEED؛ يجب أن تخرج الطابعة استيكراً واحداً فقط وتقف تماماً عند الفاصل.

## 7. إعدادات لوحة تحكم ويندوز (Windows Printing Preferences)

لضمان عدم إرسال أبعاد خاطئة من نظام التشغيل إلى الطابعة:

1. اضغط من لوحة المفاتيح على: `Windows + R`.
2. اكتب الأمر: `control printers` ثم اضغط **Enter**.
3. انقر بزر الماوس الأيمن على **طابعة الباركود الحرارية**، واختر:
   👉 **Printing preferences (تفضيلات الطباعة)**.
4. في تبويب **Page Setup (إعداد الصفحة)**:
   * اضغط على **New (جديد)** وأنشئ قالباً جديداً بالاسم (مثلاً: `Nelly_50x30`).
   * أدخل العرض والارتفاع المطابق للرول الفعلي (مثلاً Width: 50.0 mm / Height: 30.0 mm).
   * إذا كانت طابعتك بالإنش: اختر `2.00 in` للعرض و `1.20 in` للارتفاع.
5. في تبويب **Stock / Media (الوسائط)**:
   * **Method / Type:** اختر **Labels with Gaps (ملصقات بها فواصل)** أو **Die-cut**.
   * **Gap Height:** حدد `2.0 mm` (أو `0.08 in`).
   * ⚠️ *(تجنب اختيار Continuous لأنها تجعل الطابعة تتجاهل الفواصل وتطبع بلا توقف)*.
6. في تبويب **Options (الخيارات)**:
   * **Darkness (درجة السواد):** اضبطها بين **8 إلى 12** لضمان خروج خطوط الباركود سوداء ناصعة وسهلة القراءة.
7. اضغط **Apply** ثم **OK**.

## 8. إعدادات نافذة المتصفح (Chrome Print Preview)

عند النقر على "طباعة الاستيكر الحراري" في النظام، تفتح شاشة الطباعة الخاصة بالمتصفح، تأكد من الآتي مرة واحدة فقط وسيحفظها المتصفح دائماً:

1. **Destination (الوجهة):** اسم طابعة الباركود الحرارية الخاصة بك (تجنب تركها على Microsoft Print to PDF).
2. **Paper size (مقاس الورق):** اختر المقاس الذي قمت بإنشائه في الخطوة السابقة (مثل `50x30mm` أو `38x20mm`).
3. **Margins (الهوامش):** **None (بلا هوامش)**.
4. **Scale (المقياس):** **100% (أو Fit to printable area)**.
5. **Headers and footers (الرؤوس والتذييلات):** **ألغِ تفعيلها تماماً (Uncheck)** حتى لا يطبع المتصفح رابط الموقع وتاريخ اليوم على الاستيكر.

## 9. دليل المطور (Developer Usage Guide)

### أ. استدعاء نافذة باركود المنتج:
```jsx
import BarcodeModal from "@/components/BarcodeModal";

// داخل المكون:
const [isBarcodeOpen, setIsBarcodeOpen] = useState(false);
const [selectedProduct, setSelectedProduct] = useState(null);

// الاستدعاء في الـ JSX:
<BarcodeModal
  isOpen={isBarcodeOpen}
  onClose={() => {
    setIsBarcodeOpen(false);
    setSelectedProduct(null);
  }}
  product={selectedProduct} // يجب أن يحتوي على { name, barcode, sellingPrice }
/>
```

### ب. استدعاء نافذة باركود الموظف:
```jsx
import EmployeeBarcodeModal from "@/components/EmployeeBarcodeModal";

// داخل المكون:
const [isBarcodeOpen, setIsBarcodeOpen] = useState(false);
const [selectedEmployee, setSelectedEmployee] = useState(null);

// الاستدعاء في الـ JSX:
<EmployeeBarcodeModal
  isOpen={isBarcodeOpen}
  onClose={() => {
    setIsBarcodeOpen(false);
    setSelectedEmployee(null);
  }}
  employee={selectedEmployee} // يجب أن يحتوي على { name, code, role }
/>
```

### ج. تخصيص محرك الرسم (Canvas Engine):
إذا أردت إضافة حقول جديدة أو تعديل توزيع النصوص، ستجد دالة `createStickerCanvas` داخل المكونين. تأكد دائماً من:
1. عدم إضافة `ctx.strokeRect` إلا إذا طُلب إطار خارجي بشكل صريح.
2. الحفاظ على `scale = 12` (يعادل 300 DPI للطباعة الحرارية فائقة الجودة).
3. استخدام خطوط عريضة `font = "900 ..."` لضمان ظهور الأحرف العربية بوضوح على رأس الطابعة الحرارية.
4. تحرير الذاكرة دائماً عبر `URL.revokeObjectURL(blobURL)`.
